# MD Research Daily &middot; 失功能白日夢文獻日報

自動追蹤 PubMed 上關於失功能白日夢（Maladaptive Daydreaming）的最新研究文獻，由 Zhipu AI 分析彙整，每日生成繁體中文摘要報告。

## 功能

- 每日自動從 PubMed 搜尋失功能白日夢相關最新文獻
- AI 自動分析、分類、生成繁體中文摘要
- PICO 結構化分析與臨床實用性評估
- 自動部署至 GitHub Pages
- 智慧去重：只總結前 7 天尚未涵蓋的新文獻

## 搜尋範圍

涵蓋 14 組 PubMed 搜尋策略，包含：
- 核心失功能白日夢術語
- MDS-16 / SCIMD 量表驗證
- 解離、創傷、PTSD 關聯
- ADHD、OCD、自閉光譜鑑別診斷
- 行為成癮、數位行為
- 治療介入、青少年發展
- 神經科學、社會文化面向

## 技術架構

- **搜尋來源**: PubMed E-utilities API
- **AI 模型**: Zhipu GLM-5-Turbo（fallback: GLM-4.7 → GLM-4.7-Flash）
- **部署**: GitHub Actions + GitHub Pages
- **排程**: 每日 GMT+8 20:40
